5.2.5 Uses / Advantages of Stock Index Futures Asked: Sep 2025 Q4(b) 4m

  • Change weightings / risk exposure (e.g. 60% US / 40% Japan: buy US index futures, sell Nikkei).
  • Separate market timing from selection: buy index futures + PV in risk-free = market exposure; sell unwanted stocks and hold futures until new picks are decided.
  • Index arbitrage (program trading): futures above fair value → buy the basket, sell futures.
  • Hedge portfolio value against systematic risk: short hedge / sell-hedge when long the portfolio. Cash and futures must move similarly; amounts invested should be the same. Perfect hedges rare due to basis risk.
  • Flexibility; leverage; keep the portfolio through corrections without selling; sell as readily as buy (same margin); transfer risk quickly and efficiently (vs once-a-day MF pricing).

SM hedge example: portfolio $1.2 million, β 1.00, α 6%; market −15% + 1% dividend = −14%, expected −8%. To halve β: S&P 240 × $500 = $120,000 per contract → sell 5 contracts ($600,000). Cheaper than selling shares (capital gains tax, commissions).

7.3 Black-Scholes Model Asked: May 2026 Q6(b) 7m TYK T3

  • Theoretical price = what a writer needs as compensation for writing a call and completely hedging by buying stock. Hedger's view of future prices is irrelevant → risk-neutral valuation (underlying assumed to earn the risk-free rate). Based on a normal distribution of returns.
  • Assumptions: European options; no transaction costs; short-term interest rates known and constant; stocks pay no dividend; price follows a random walk; returns normally distributed; variance constant over the option's life.
  • Advantage: speed. Limitation: cannot accurately price American options — values only at expiry, ignores early exercise.

9.3.2 Abandonment Option Asked: Jan 2026 Q6(b) 4m

  • Like an American put: exercise if the value from the project's assets (disposal) exceeds PV of continuing. Pay-off = Max(0, abandonment value − project value).
  • Risk-neutral p from returns: risk-free rate = p × up return + (1 − p) × down return (as Illus 5: 8% = p × 30% + (1 − p) × (−40%)); value = expected pay-off ÷ (1 + risk-free rate).

Illus 5 (IPL): PV 100 crore → 130 (+30%) / 60 (−40%); disposal 80 → pay-off 0 / 20. 0.08 = 0.30p − 0.40(1 − p) → p = 0.48/0.70 = 0.686; expected 0.314 × 20 = 6.28 crore; ÷ 1.08 = ₹ 5.81 crore (value of put).

Exam steps

Exam steps — futures price and arbitrage: 1 → pick formula by what is given (simple S + S·r·t − div; compound (1 + r/n)nt; continuous Sert, (S − PV div)ert, Se(r − y)t) → 2 → compare with quoted futures → 3 → quoted > fair: borrow, buy spot, sell futures; quoted < fair: sell spot, invest, buy futures → 4 → profit = difference at expiry (TYK P2, P4, P6).

Exam steps — beta hedge with index futures: 1 → portfolio β = Σ wβ (cash β 0) → 2 → contract value = futures price × lot → 3 → contracts = value × β ÷ contract value (long cash → sell; short cash → buy; net long and short positions) → 4 → change β: P(β − β′) ÷ F → 5 → close-out P/L = change in shares + change in futures (TYK P5, P7–P13).

Exam steps — margin account: 1 → initial = µ + 3σ; maintenance = % of initial → 2 → daily MTM = lot × change in closing price → 3 → balance < maintenance → call to restore initial (TYK P14).

Exam steps — option pay-offs / call + put combinations: 1 → total premium paid → 2 → at each expiry price, exercise only the leg in the money (call S > X, put S < X) → 3 → net = exercise gain × lot − total premium → 4 → break-evens: call strike + total premium, put strike − total premium (TYK P15, P16, P19, P20).

Exam steps — binomial / risk-neutral: 1 → pay-offs at expiry → 2 → u, d, r (as given: compound, simple, ert) → 3 → p = (r − d)/(u − d) → 4 → value each node backwards: [p·Cu + (1 − p)·Cd] ÷ r → 5 → hedge ∆ = (Cu − Cd)/(Su − Sd) shares per call written (Illus 1, 2, TYK P21, P23, P24).

Exam steps — riskless hedge: 1 → ∆ = (Cu − Cd)/(Su − Sd) → 2 → end value of ∆ shares − call written (same both states) → 3 → (∆S0 − C0) × r = end value → C0 → 4 → expected return uses real probabilities (TYK P22).

Exam steps — Black-Scholes: 1 → adjust S for PV of dividend (D e−rt) → 2 → loge(S/X), (r ± v²/2)t, v√t → d1, d2 = d1 − v√t → 3 → N() from table type given (one-tail: 1 − area for +z, area for −z), interpolate → 4 → C = S·N(d1) − X e−rt N(d2) → 5 → put = −S + C + PV(X) → 6 → compare with market premium; state N(d1) = hedge ratio, N(d2) = probability of exercise (Illus 3, TYK P25).

Exam steps — real options: 1 → identify type (growth = European call; abandonment = American put; timing = American call) → 2 → up/down values and returns → 3 → p from risk-free rate = p × up return + (1 − p) × down return → 4 → option pay-off in each state → 5 → PV of expected pay-off at rf; patent → B-S with e−Dt (Illus 4, 5, 6).

5.8 Broken period forward rate Asked: Sep 2025 MCQ CS-IV 6m

  • Interbank forwards are for standard amounts and standard month-end dates; customer deals are odd amounts and odd dates (export bill realised 23 Feb). Points for the odd date are interpolated — assumed to grow uniformly (pro rata) over the period.
  • SM: premium for the odd date = 10*53/59 paise, "53 & 59 are broken & full periods", i.e. full-period points × broken period ÷ full period. Between two standard dates (TYK P5): (c) = (b) − (a) for the month between, (d) = (c)/2 for 15 days, (e) = (a) + (d).
  • Then: merchant forward rate = spot ± broken points ± bank's margin (margin deducted for exporter, added for importer).

SM example: 1 Jan spot ₹ 62, 2-month (28 Feb) premium 10 paise → 62.10; margin 3 paise → importer 62.13, exporter 62.07. For 23 Feb: 10 × 53/59 = 8.98 paise → 62.0898 ≈ 62.09 → exporter 62.06, importer 62.12.

TYK P5 (Sep 2025 MCQ type): 2m points 70/90, 3m 160/186 → 30 days 90/96 → 15 days 45/48 → 2m 15d = 115/138 (1 point = 0.0001) → rate for 20 June = 66.2525 + 0.0115 = 66.2640 / 67.5945 + 0.0138 = 67.6083. Annual premium on average rate: bid 0.0115 ÷ 66.2583 × 12/2.5 × 100 = 0.0833%; ask 0.0138 ÷ 67.6014 × 12/2.5 × 100 = 0.0980%.

10. Foreign Exchange Exposure Asked: May 2026 Q5(c) 2m

  • Exposure: "a contracted, projected or contingent cash flow whose magnitude is not certain at the moment; depends on FX rates and interest rates". FX exposure = parts of business affected if exchange rates change.
  • Examples: traveller (destination currency appreciates); exporter invoicing in FC (FC falls → lower home revenue); importer (FC appreciates → higher cost); fund managers owning foreign assets (currency falls); trade in local currency where rates move the negotiated price.
  • Timing view: translation and transaction exposure look at the moment of the rate change (accounting / settled obligations); operating (economic) exposure looks at expected future cash flows after an unexpected change.

Automatic cancellation (FEDAI Rule 6): an overdue forward contract with no instructions on or before due date is automatically cancelled within 3 working days after maturity. Customer pays any exchange difference but is not entitled to any profit. Late delivery → fresh contract at spot; extension after due date → forward rate for the desired period. Charges:

  • (i) Exchange difference: spot rate of offsetting position on the cancellation date (or 3 working days, whichever is earlier) vs contract rate.
  • (ii) Swap loss: bank offsets at spot on the due date and takes the opposite position at the earliest forward.
  • (iii) Interest on outlay of funds: (bank's interbank cover rate − spot of opposite position on due date) × FC amount, for the period from due date to actual cancellation or 3 working days, whichever is later.
  • Any profit to the bank is not passed on to the customer.

Exam steps — swap ratio and post-merger EPS/MPS: EPS, MPS, P/E for both (derive missing one: MPS = EPS × P/E) → ER on the stated basis (target ÷ acquirer) → shares issued = target's shares × ER → post EPS = total earnings (+ synergy) ÷ total shares → target's equivalent EPS = post EPS × ER → post MPS = post EPS × given P/E → compare each group with pre-merger figures.
Exam steps — maximum exchange ratio: EPS-based: combined PAT ÷ acquirer's EPS − existing shares = max shares to exchange → ratio to target's shares. MPS-based: combined market capitalisation (or earnings × P/E) ÷ acquirer's MPS − existing shares → ratio to target's shares. Range question: lower = market price ratio, upper = intrinsic value ÷ acquirer's MPS; say which end and why (EPS, P/E, ROE, growth).
Exam steps — gains and true cost: VA, VB → VAB (sum + synergy, or P/E × combined earnings, or DCF) → gain = VAB − (VA + VB) → each group: % holding × VAB − own pre-merger value → true cost = target's share − VB (share deal). Max price = (VB + synergy + savings) ÷ target's shares; min price = (holding + lost benefits) ÷ shares.
Exam steps — weighted swap / promoter / free float: per-share MPS, EPS, BVPS for both (from market cap, P/E, capital + reserves; from free float ÷ public %) → each ratio T ÷ A (bank NPA: A ÷ T) × weight → sum = ER → shares issued → promoter % = (A's promoters + T's promoters × ER) ÷ total → post EPS, MPS (A's P/E), market cap → free float = MPS × public shares → bonus/split if asked.
Exam steps — cash acquisition: EPS-neutral: (net profits of both − x × interest rate × (1 − tax rate)) ÷ acquirer's shares = acquirer's present EPS → x. Own cash: lost return on cash vs target earnings → EPS change × P/E. Project view: net consideration (shares + liabilities + debentures − realisations − cash taken) → NPV of division cash flows + disposal value.
Exam steps — demerger: split assets and outside liabilities at book value → net worth of each → new co. EPS = expected MPS ÷ sector P/E → shares = profit ÷ EPS → ratio to old shares → remaining co. MPS = EPS × its P/E → BVPS = net worth ÷ shares.

4.1.2 Forward Rate Agreements (FRAs) Asked: Sep 2025 Q2(b) 4m

Features (TYK T1 — short note):

  • Agreement by which a borrower/lender protects itself from unfavourable rate changes; OTC, not exchange-traded (unlike futures).
  • Used by banks to fix interest cost on anticipated deposits or revenue on variable-rate loans indexed to a benchmark (SOFR, €STER, MIBOR).
  • Off-balance sheet; no transfer of principal — principal is notional.
  • Cash-settled at maturity for the profit/loss. Seller pays buyer the increased interest cost if RR > FR; buyer pays seller if RR < FR. So a borrower buys an FRA (protection against a rise).
  • Differential is discounted at the actual (post-change) rate because it is settled at the beginning of the period, not at the end.

4.2.2.1–4.2.2.2 Cap Option and Floor Option Asked: Jan 2026 Q4(a) 6m

  • Cap (call option): buyer pays premium for the right to receive the excess interest whenever the index rises above the cap rate; no obligation if rates fall. Bought by a borrower on floating-rate debt. Evolved from guarantees on floating-rate loans; OTC caps from 1985 (banks stripped guarantees from FRNs); spurred by the leveraged buyout boom of the 1980s (lenders required LBO borrowers to buy caps); activity declined as LBOs fell.
  • Cap is characterised by: notional principal; benchmark (SOFR, MIBOR, PLR) of a specified maturity; cap rate (= strike); period incl. payment and reset dates. Payments follow swap conventions; reset intervals usually equal the benchmark's term.
  • First period is excluded — its rate is known on the agreement date.
  • Floor (OTC): protects the buyer against a fall in rates — bought by a lender/depositor. Payoff when rate < floor rate = payoff from selling an FRA; above floor → nothing, premium lost. Floor = European put on an FRA; multi-period floor = bundle of European puts on a sequence of FRAs.

6.1 Sustainable Growth Rate Asked: May 2026 Q1(c) 4m

  • SGR (Robert C. Higgins) = maximum rate of growth in sales achievable given the firm's profitability, asset utilisation, desired dividend payout and debt (financial leverage) ratios.
  • Measures how much a firm can grow without borrowing more money; beyond it, the firm must borrow from another source.
  • Variables: net profit margin on new and existing revenues; asset turnover (sales ÷ total assets); assets to equity ratio; retention rate (fraction of earnings retained).
FormulaTerms / logic
SGR = ROE × (1 − Dividend payout ratio)ROE = return on equity; (1 − d) = retention rate. Logic: only new equity is retained earnings, and the asset to beginning-of-period equity ratio is constant (debt grows in step) → sales and assets grow no faster than retained earnings plus the debt they support.

Note (app-written): ROE itself is built from the SM's other three variables — net profit margin × asset turnover × assets to equity — so SGR moves up with any of the four.

Assumptions — the business wants to:

  • maintain a target capital structure without issuing new equity;
  • maintain a target dividend payout ratio;
  • increase sales as rapidly as market conditions allow.
  • Consistent with evidence that corporations are reluctant to issue new equity; if willing to issue equity, there is in principle no financial constraint on growth. Formula is directly predicated on ROE.
  • Twin cornerstones: growth strategy and growth capability — strategy without infrastructure to execute (or the reverse) → long-term growth impossible.
  • Concepts of sustainability: very weak — overall stock of capital assets remains constant; weak — preserve critical resources to support all over a long horizon; strong — preserve resources under primacy of ecosystem functioning.

What makes an organisation sustainable? It must:

  • have a clear strategic direction;
  • be able to scan its environment to identify opportunities;
  • be able to attract, manage and retain competent staff;
  • have adequate administrative and financial infrastructure;
  • demonstrate effectiveness and impact to leverage further resources;
  • get community support and involvement.

Use of SGR model:

  • Borrower requests additional financing (actual growth > SGR): risk of too much debt, too little equity → either raise additional equity, or reduce the rate of expansion to a level sustainable without more financial leverage.
  • Mature firms (actual growth < SGR): find productive uses of excess cash — increase dividends / buy back stock, reduce debt, or hold more lower-earning liquid assets (these lower SGR); or acquire rapidly growing companies to raise actual growth.
  • Inflation: growth = volume + inflation; inflationary asset increase must be financed like real growth → more external financing and higher historical-cost D/E → if creditors fix historical D/E, inflation lowers SGR.

Mitsubishi Corporation (SM case): dropped fixed 3-year "midterm management plan" for a long-term circa-2020 growth vision ("New Strategic Direction"); aim — stable earnings through business cycles by a portfolio diversified by business model, industry, market and geography; "Three Corporate Principles". Summary:

  • Future pull approach eyeing 2020 — double the business with a diversified but focussed portfolio;
  • Clear portfolio strategy — select winning businesses by proactive reshaping;
  • Grow and deliver returns while keeping financial discipline.

5.1.1 Bootstrapping Asked: May 2026 Q2(c) 4m

Bootstrapping = start and build a company from personal finances or operating revenues of the new company. Logic: more money at inception → complacency and wasteful spending (marketing, offices, equipment); own savings → cautious approach, curbs waste, keeps promoter on toes. Methods:

  • (a) Trade credit: suppliers reluctant to new businesses (want cash/credit card). Way out: well-crafted financial plan, visit supplier (owner if small, CFO if big firm), communication skills, reference of someone known to the supplier. May get half on credit, balance on delivery. Trick: get goods shipped and sell before paying. Reduces working capital needed, especially in retail.
  • (b) Factoring: receivables sold to a commercial finance company; factor collects and does the paperwork; can be on a non-notification basis (customers not told). Merits: cuts receivable-maintenance costs (bookkeeping, collections, credit verification) — often cheaper than the factor's fee; frees money tied in receivables, esp. sales to businesses/government with long payment delays.
  • (c) Leasing: lease equipment instead of buying → lower capital cost, lessee claims tax benefit. SM figures: photocopier at ₹ 5,000 per month vs ₹ 1,00,000 or more to buy; automobile/van to avoid ₹ 5,00,000 or more. Lessor: depreciation tax benefit, possible capital appreciation, profit on lease. Lessee: smaller payments, ability to walk away at end of lease term, tax benefit on lease rentals.

5.1.2 Angel Investors Asked: May 2026 Q2(c) 4m

  • Context: India ranks low on entrepreneurship, innovation and ease of doing business — outdated draconian rules, red tapism, time-consuming procedures, lack of general support; changing in recent times.
  • Invest in small startups or entrepreneurs; often among the entrepreneur's family and friends; one-time investment or ongoing injection through difficult early stages.
  • More favourable terms than other lenders — invest in the entrepreneur rather than the viability of the business; focus on helping first steps, not possible profit → different from VCs.
  • Also called informal investors, angel funders, private investors, seed investors, business angels: affluent individuals; capital in exchange for ownership equity or convertible debt; some via crowdfunding platforms or angel networks.

2.4.2 Elliot Wave Theory Asked: May 2026 Q4(c) 4m TYK T3

  • Ralph Elliot, 1934; inspired by Dow Theory and nature; based on 75 years of price movements and charts.
  • Wave = movement of market price from one change in direction to the next change in the same direction; caused by buying/selling impulses from demand-supply pressures.
  • Impulsive patterns (basic waves): 3 or 5 waves in the direction of the basic movement (bull or bear phase).
  • Corrective patterns (reaction waves): 3 waves against the basic direction; correct the earlier rise (bull) or fall (bear).
  • Waves 1, 3, 5 = directional; waves 2, 4 = corrective.
  • Complete cycle: five-wave impulse + three-wave correction (a, b, c) = 8 waves; two phases, bullish and bearish; then a fresh cycle starts.

7.1 Pass Through Certificates (PTCs)

  • Originator transfers the entire cash receipt (interest + principal) from assets sold → direct claim of investors on all securitized assets via SPV.

  • Prepayment of principal distributed proportionately to all holders.

7.2 Pay Through Security (PTS) — overcomes PTC's limitation of all cash flows being passed on and of single maturity.

  • SPV issues debt securities backed by the assets → can restructure tranches from varying maturities of receivables.
  • Permits desynchronisation of servicing of securities from asset cash flows.
  • SPV may reinvest surplus funds short term (e.g. on early retirement of receivables, for short-term yield).
  • Freedom to issue several debt tranches with varying maturities.

6.3 Economic Value Added (EVA) Asked: Jan 2026 Q4(b) 4m

  • Holistic measure of financial performance and economic contribution. A company creates value only if returns exceed its cost of capital. EVA separates operations from financing. Negative EVA → not generating value; positive → producing value.
  • Why EVA: ROI, ROCE, asset/earnings/FCF methods are "number-crunching"; EVA makes management accountable for decisions (e.g. choosing only the earlier break-even project although both had positive IRR) and shows whether returns cover the cost of capital.

Exam steps

Exam steps — Relative valuation / EV (Sep 2025 type): ke = rf + β (rm − rf) → adjust EBITDA for extraordinary / pending items → EV = EBITDA × multiple → Equity value = EV − debt + surplus cash (÷ shares) → or EV = shares × CMP + debt − cash.
Exam steps — EVA (Jan 2026 type): PAT ÷ (1 − t) = PBT → + interest = EBIT → NOPAT = EBIT(1 − t) (+ non-cash items) → invested capital (equity + debt, or assets − non-interest CL, + unrecorded patents) → WACC (ke by CAPM, kd(1 − t), weights) → capital charge → EVA → EVA ÷ shares = max DPS. MVA = market value − invested capital.
Exam steps — DCF / FCFF: high-growth WACC and stable WACC (CAPM + kd(1 − t)) → FCFF = EBIT(1 − t) − (capex − dep) − ∆WC each year → PV at high-growth WACC → TV = terminal-year FCF ÷ (stable cost of capital − growth rate) → discount TV by PVF of the last explicit year → firm value (− debt + non-core assets = equity, as in SVA).
Exam steps — Unlisted firm / new project: proxy βe → de-gear βa = βe × E/[E + D(1 − t)] → average → re-gear at own D/E → CAPM ke → WACC → discount FCFs.
Exam steps — Several methods / exchange ratio: NAV per share (deduct contingent liability if it will materialise) → earnings capitalisation (maintainable PAT ÷ rate) → PE × EPS → DCF → weighted / average fair value → range (seller's minimum to buyer's maximum) → exchange ratio = target value ÷ acquirer value; allocate shares on fully-paid equivalents.
Exam steps — Chop-shop / distressed: segment data × pure-play ratios (sales, assets, operating income) → average = break-up value vs market. Distressed: DCF value of equity (1 − Probability of distress) + Distress sale value of equity (Probability of distress); APV = Unlevered Firm Value + Tax Benefits of Debt − (Unlevered firm value − Distress Sale Value) × Probability of Distress.
