TechnologyWhat it does in accounting / when ICAI picks it
RPA (robotic process automation)Software bots for repetitive, rule-based tasks: reconciliations, consolidation data collection, intercompany eliminations, journal postings. Sep 2025 answer: consolidation across 8 subsidiaries → RPA (Example 1).
BlockchainDistributed, immutable ledger; real-time verification, audit trail, smart contracts, supply-chain tracking, secure sensitive data. Sep 2025 answer: sensitive customer data → blockchain (Examples 3–5).
Cloud computingStorage and computing over the internet: SaaS (accounting/ERP software), IaaS (servers, storage), PaaS (build apps); collaboration on the same file, remote access, scalability, backup. May 2026: define + four applications — ICAI lists storage, SaaS, IaaS, PaaS, collaboration, e-commerce, big data, streaming (Example 2).
AI / machine learningPattern recognition: fraud detection, estimates (ECL, impairment), contract review, forecasting; human judgement still needed.
Data analytics / big dataDescriptive, diagnostic, predictive, prescriptive; dashboards (segment reporting — TYK 1).
ERP and controlsIntegrated ledgers, inventory costing under Ind AS 2 (Illus 2); controls against backdating and unauthorised postings (Illus 1: review posting vs transaction date, access rights, audit trail).
XBRL, IoT, cyber securityStructured digital reporting to regulators; sensor data for asset tracking; protect data (access controls, encryption).
Applying technology to Ind ASAutomated workflows: Ind AS 115 contract identification and distinct POs (Illus 4; TYK 2; Nov 2024 PYQ), Ind AS 109 derivative vs own-use classification (Illus 3), Ind AS 108 segment aggregation (TYK 1). Steps: collect data → define criteria/rules → automate evaluation → flag exceptions → human review → report.
Answer frame (5 marks): name the technology → what it is (one line) → 3–4 specific uses for the facts given → benefit (accuracy, speed, audit trail, security) → limitation / control needed.
